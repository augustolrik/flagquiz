# Flagquiz

Dansk flagquiz med 10 runder: gæt flaget blandt fire svar, og find derefter landet på et Equal Earth-kort uden landenavne. Ét point for hvert rigtigt trin, højst 20 point.

Spil: https://augustolrik.github.io/flagquiz/

113 rigtige flag, zoom og flytning af kortet, grønne svarnåle og en samlet score. Ingen konto er nødvendig. Se [materialekilder](CREDITS.md).
